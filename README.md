# Personal Portfolio Website

A simple and responsive personal portfolio website built using HTML, CSS, and JavaScript. This website showcases my profile, technical skills, projects, internship experience, certifications, and contact information.

## 🌐 Live Demo

https://vynavipotnuru.github.io/portfolio/

## 🛠️ Technologies & Tools Used

### Languages
- HTML5
- CSS3
- JavaScript

### Development Tools
- Visual Studio Code (VS Code)
- Git
- GitHub
- GitHub Pages

## ✨ Features

- Responsive Navigation Bar
- Home Section
- About Me Section
- Skills Section
- Internship Experience
- Projects Showcase
- Certifications Section
- Contact Information
- Smooth Scrolling using JavaScript
- Responsive Design

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/vynavipotnuru/portfolio.git
```

2. Open the project folder in **Visual Studio Code (VS Code)**.

3. Open `index.html` in your browser or use the **Live Server** extension in VS Code.
